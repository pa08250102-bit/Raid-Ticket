# Stumble Raid Ticket Bot

Comandos:
- `/ping`
- `/ticketpanel`

O painel cria tickets de Denúncias, Dúvidas, Compra e Suporte.
O cargo da equipe é `CC`.

No Railway, crie a variável `DISCORD_TOKEN` nos Variables/Secrets.
Nunca coloque o token no GitHub ou envie o token no chat.

Permissões recomendadas:
View Channels, Send Messages, Read Message History, Embed Links e Manage Channels.

Scopes:
bot e applications.commands.
